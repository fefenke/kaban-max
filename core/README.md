# Исходники сетевого ядра

Ядро K.A.B.A.N.-MAX собирается из закреплённого upstream и открытой серии патчей. Источник истины — [UPSTREAM](UPSTREAM): commit `60d96c99815a672712915a5c00114bf0f690ad80`, версия пакета **1.14.4-r47**, Go **1.26.10**.

Все **46 патчей** из [patches](patches/) применяются по имени к чистому upstream. Затем выполняется [переименование](../scripts/brand-core.py). Приватные рабочие копии не являются источником выпуска.

## Сборка

Из корня проекта:

```sh
bash scripts/build-core.sh base aarch64_cortex-a53 dist/release
```

Варианты сборки — `base`, `tiny`, `full`; поддерживаемые скриптом архитектуры — `aarch64_cortex-a53` и `x86_64`. В публичном выпуске готовые пакеты представлены только для **base/tiny ARM64**. Наличие варианта в скрипте не означает наличие готового пакета.

Требуются Git, Python 3, Bash, GNU tar, curl, zstd, Go с загрузкой закреплённого toolchain и apk v3 для упаковки APK. Окружение описано в [release Dockerfile](../scripts/release.Dockerfile).

Серия содержит маршрутизацию DNS/FakeIP, устойчивый fallback, профили TLS, авторутинг, ограничение диагностических данных, восстановление WARP и политику журналирования. Текущие контракты:

## Проверки и распространение

Команды, даты и ограничения проверок находятся в [TESTING](../docs/TESTING.md) и [текущем состоянии](../docs/PROJECT_STATE.md). Скрипты `tests/core/run_*.sh` получают чистые исходники и применяют серию перед тестами. Прошедший локальный тест не заменяет аппаратную приёмку.

При распространении бинарников сохраняйте соответствующие исходники и обязательные уведомления лицензий. Исходный архив и его SHA256 публикуются рядом с пакетами. [Лицензии и авторы](../CREDITS.md).
