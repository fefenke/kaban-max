# Изменения

## 0.1.8 preview — 2026-11-16

- Общие формы и настройки: компактные синие вопросики справа от подписей, одна колонка галочек и полей без лишних вложенных отступов; адаптация узких экранов сохранена.
- Автомаршрутизация: уже включённое автоматическое применение можно выключить без strict-контракта и при выключенной главной настройке. Включение без необходимых условий по-прежнему запрещено.
- Компактные стрелки страниц справа, справка реестра под вопросиком, удалена кнопка временной остановки. Ошибки и результаты действий остаются видимыми.
- «Удалить все» в «Применены» удаляет активные маршруты и сохранённые разрешения текущего фильтра; в «Исключены» снимает исключения того же фильтра. Обрабатываются все его страницы только выбранной исходной секции, с подтверждением и частичными результатами.
- Ядро остаётся 1.14.4-r12; сетевые алгоритмы и ограничения ordinary/IP-only не меняются. Проверка установленной LuCI-темы на оборудовании не выполнялась.

## 0.1.7 preview — 2026-11-16

- Core r12: до 64 RAM-наблюдений/leases, exact source/scope suppression API, безопасный restore сохранённых strict intents после нового flow и verifier, без продления исходного TTL.
- Отдельное atomic хранение applied/excluded, бюджет записи во flash, отказ при переполнении без молчаливого удаления; scoped bulk и удаление одного исключения с partial results.
- Страницы по 25, единые подсказки и выравнивание, textarea от шести строк с переносом, скрытие пустых auto-вкладок; ранее подготовленные обновления/Диагностика/VPN/uTLS из UI v2 включены.
- Ordinary HTTPS остаётся manual-only, IP-only — диагностика/точное исключение. Hardware/real egress не проверены. [Контракт и ограничения](docs/AUTO_REGISTRY_017.md).

### Подготовлено ранее в UI v2, включено в 0.1.7

- Общие CBI подсказки по клику рядом с названием, scoped alignment; Диагностика со свёрнутым forecast и LAN chooser.
- Компактный VPN editor с сохранением URI и каталогом browser/version; source-only Zapret2 controls и серверные страницы ограниченного IP snapshot.
- Честные ограничения r11 для IP-only/generic auto-apply и filtered bulk/reset; [полный отчёт](docs/audits/UI_FIXES_V2.md).
- На этом предыдущем этапе публикация была отменена; новое ТЗ разрешило выпуск 0.1.7 после проверок.

## Не выпущено

- WARP: запросы Cloudflare API используют dialer ядра с обходом собственного перехвата; автоматическая регистрация также учитывает выбранную секцию запросов профиля. Добавлены локальные регрессии Save & Apply и повторов API. Полевые проверки холодного старта ещё требуются.

- uTLS: общий каталог и выбор семейства/версии (Chrome 133/155), Randomized, QQ и 360. Дублирующие Chrome-алиасы сохранены для старых настроек, но не предлагаются новым выбором. Проверены действительные ClientHello/handshake/parser и ограничения REALITY; ядро и uTLS не обновлялись.

- Редактор параметров VLESS/REALITY, Trojan, AnyTLS и основных HTTP(S)/SOCKS-полей: импорт, редактирование без пересоздания записи и явный экспорт с эффективным fingerprint. Неизвестные параметры и URI без правок сохраняются; специальные форматы остаются raw. Добавлены русские подписи и регрессии сохранения, ссылок URLTest/Fallback и жизненного цикла старых TCP-сессий при reload.

- Fallback: переименование ручного VPN-подключения обновляет точные списки выбранных/исключённых серверов в уровнях этой секции; удаление очищает ссылки, чтобы новое одноимённое подключение не наследовало старый выбор. Порядок уровней и схема UCI сохранены.

## 0.1.5 — предварительная версия

- Ядро 1.14.4-r9: отдельный отпечаток `chrome_155` из закреплённого uTLS-lx. Обычный `chrome` остаётся Chrome 133; значение сохраняется в ссылках и подписках. Добавлен выбор в параметрах клиента сервера.
- Выбор отпечатка TLS для отдельного подключения по постоянному ID: наследование из URI либо явный override уже разобранного outbound. Название и URI не меняются, одноимённые подключения независимы.
- Сообщения проверок обновлений KabanMax и Zapret2 приведены к одному стилю: успешный результат зелёным над кнопкой.
- Генератор каталогов использует общую подпись проекта; служебные заголовки каталогов унифицированы.
- Сборка применяет всю серию patches; версия ядра в release manifest берётся из UPSTREAM. Проверены локальные ARM64 base/tiny. Ограничения ML-DSA и trust anchors описаны в `core/CHROME155.md`.
