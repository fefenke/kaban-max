# Установка локального preview с Windows-компьютера

2026-11-27. Текущий локальный комплект0.2.3/core r46 ещё не опубликован; GitHub release0.2.3 описывает r41. Для r46 нельзя использовать обычную загрузку с публичного release. Источник — проверенные файлы `dist/auto-routing-r46/release` с последним LuCI combobox и DNS guard.

`scripts/update-local-preview.ps1 -Routers @(...)` передаёт только подходящие файлы и запускает неизменённый штатный install.sh через локальное loopback зеркало каждого роутера. Нужны Windows OpenSSH и root SSH-доступ. Не отключается проверка host key; пароль запрашивается OpenSSH и не сохраняется. Скрипт не ставит SSH-ключи и не чинит отказ авторизации. Пакеты core доступны только для собранной архитектуры и base/tiny; установленный вариант сохраняется, неподдержанный пропускается с предупреждением.

Пример из корня проекта, адреса документационные:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "& '.\scripts\update-local-preview.ps1' -Routers @('192.0.2.1','198.51.100.2')"
```

Bypass относится только к этому процессу PowerShell; ExecutionPolicy глобально не меняется. Скрипт сначала проверяет локальные SHA, получает package format/arch/variant через SSH и передаёт подходящие четыре APK либо IPK + installer/manifests/sums во flash. Все передачи заканчиваются до запуска установщиков. Для каждого пакета SHA проверяется повторно на роутере. Не нужно загружать оба варианта/формата или держать ядро и его копию в RAM.

Runner — отдельный LF-файл. Запуск через `setsid sh PATH/run.sh` без вложенного `sh -c`, который ранее сломался при Windows quoting. Задержка перед установкой120секунд, затем штатный installer выполняет проверки/остановку/transaction/start независимо от SSH. Есть `-DelaySeconds` для другого интервала. Каждый mirror слушает только127.0.0.1:18083 и завершается с runner. Переданные собственные пакеты удаляются после завершения; при ошибке staging предусмотрена попытка удалить только пакеты своего уникального каталога. Установленные файлы, конфиги, cache/checkpoints и rollback данные не удаляются.

Через задержку плюс несколько минут проверить:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "& '.\scripts\update-local-preview.ps1' -Status"
```

Статус берётся из последнего run-state под ignored `dist/router-updates`. Он содержит адреса/пути/состояние, без паролей и конфигов; не публиковать его. Установщик пишет bounded вывод своей операции в `/tmp/kabanmax-pc-ID.log` и код выхода в `.exit`. `INSTALL_EXIT=0`, версия r46 и running подтверждают запуск; до появления exit успех не заявляется. При launch_unconfirmed сначала проверять статус, не удалять файлы работающего установщика. Если файл exit отсутствует, лог/версия помогают отличить ещё работающий процесс от незапущенного; автоматически рестартовать службу скрипт проверки не пытается.

Просмотр без соединения с устройствами: тот же install вызов с `-WhatIf`; он проверит локальные артефакты и перечислит цели, без записи run-state/загрузки/SSH. Не включает локальный gateway автоматически: цели задаёт пользователь.

## Локальная проверка27ноября

`powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/scripts/update-local-preview.test.ps1` — PASS: WhatIf без SSH, проверка текущих13SHA локального комплекта, dedup целей, сохранение base/APK и tiny/IPK, обе передачи до первого launch, отдельный LF runner без nested sh-c, чтение статуса, отказ неподдержанного target и cleanup/отсутствие launch после неудачной передачи. SSH/SCP полностью подменены локальными functions с адресами RFC documentation ranges; реальной авторизации/сетевого доступа не было. Первое assertion падало из-за интерполяции `$4` в самом test regex, заменено на буквальную проверку shell quoting; production quoting сохранился.

Отдельный реальный PowerShell `-WhatIf` и parser PASS; исходный direct `.ps1` запуск был остановлен пользовательской ExecutionPolicy, поэтому клиентская команда использует только process Bypass. `docker exec ... sh -n` на созданном runner — PASS shell syntax, без запуска. Тесты не доказывают успешность SSH auth, свободное место/архитектуру или установку на оставшихся устройствах. Ассистент в этой задаче к ним не подключался.
