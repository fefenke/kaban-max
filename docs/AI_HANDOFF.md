# Продолжение в другом чате

Постоянный указатель: версии и результаты здесь не дублируются.

1. Открыть KABAN-MAX, прочитать [AGENTS](../AGENTS.md).
2. Прочитать [PROJECT_STATE](PROJECT_STATE.md), проверить `git status --short`.
3. По [DEVELOPMENT_INDEX](DEVELOPMENT_INDEX.md) выбрать тему и изменяемые символы.
4. Один ассистент без агентов; `resource budgeting` или его fallback из [WORKFLOW](WORKFLOW.md).
5. Сохранить существующий diff. Старый отчёт не разрешает повторный выпуск, установку или эксперимент.
6. После изменения обновить документы и запустить `python scripts/check-project-docs.py`.

Для обычного чата без доступа к папке передать AGENTS, PROJECT_STATE, DEVELOPMENT_INDEX и выбранный тематический документ. Файлы не создают доступа к проекту и не заставляют произвольный клиент автоматически читать их.
