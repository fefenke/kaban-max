# URI подключения

## Редактор параметров (локальная версия после 0.1.5)

После добавления ссылки открываются параметры сервера. Для VLESS (TLS/REALITY), Trojan и AnyTLS доступны адрес, порт, учётные данные и поддерживаемые TLS-поля. Для VLESS/Trojan доступны TCP, WebSocket, gRPC, HTTPUpgrade, HTTP и XHTTP с соответствующими параметрами. Для HTTP(S) и SOCKS доступны основные поля адреса и учётной записи. Имя сервера в интерфейсе задаётся отдельно от UUID/пароля.

Чтобы заменить ссылку целиком, переключитесь на **Исходная ссылка**. Можно сохранить её напрямую или нажать **Разобрать на поля**. При переходе на поля после изменения исходной ссылки требуется повторный импорт, чтобы старые поля не затёрли новые данные. Открытие и сохранение без изменений сохраняют исходные байты URI, неизвестные параметры и fragment. Изменение параметров обновляет ту же запись, сохраняя её ID и порядок.

**Скопировать ссылку** экспортирует действующие переносимые значения. В VLESS/Trojan/AnyTLS отдельный TLS fingerprint имеет приоритет над fingerprint в URI и попадает в экспорт; исходный URI при выборе override не переписывается. Имя в экспортируемом fragment соответствует имени сервера. Разбиение ClientHello, классический обмен ключами и каскад не входят в стандартную ссылку и остаются отдельными настройками.

VMess (base64/JSON), Shadowsocks, Hysteria, TUIC, Naive, Mieru, TrustTunnel и неоднозначные/неизвестные варианты остаются в режиме исходной ссылки. Для них не заявляется двусторонний редактор полей. Если формат не умеет переносить отдельный fingerprint, экспорт с override отказывается с пояснением вместо выдачи ссылки с другим действующим отпечатком. Параметры подписок этот редактор не меняет.

При переименовании/удалении ручного сервера точные списки выбора и исключения в Fallback и URLTest этой секции обновляются. Regex остаётся шаблоном и может требовать ручной правки; ранее потерянные связи автоматически не восстанавливаются.

Ссылка на сервер в том виде, в каком её выдают VPN-сервисы и панели. Поле принимает такие схемы:

| Протокол | Схема | Сборка ядра |
| --- | --- | --- |
| VLESS, включая Reality, XTLS Vision и XHTTP | `vless://` | все |
| Trojan | `trojan://` | все |
| Shadowsocks, включая Shadowsocks 2022 | `ss://` | все |
| Hysteria2 | `hysteria2://`, `hy2://` | все |
| Hysteria | `hysteria://`, `hy://` | все |
| TUIC | `tuic://` | все |
| SOCKS | `socks://`, `socks5://`, `socks5h://`, `socks4://`, `socks4a://` | все |
| HTTP | `http://`, `https://` | все |
| VMess | `vmess://` | base, full |
| AnyTLS | `anytls://` | base, full |
| TrustTunnel | `tt://` | base, full |
| NaiveProxy | `naive+https://`, `naive+quic://`, `http2://`, `http3://` | full |
| mieru | `mieru://`, `mierus://` | full |

Ссылки `wireguard://` и профили Amnezia `vpn://` добавляются в поле **Туннель**, см. [Туннели](/tunnels/).

## Fingerprint отдельного подключения

В локальной версии после 0.1.5 сначала выбирается семейство отпечатка; у Chrome доступен выбор **Стандартная (Chrome 133)** / **Chrome 155**. Для семейств с единственным профилем лишний список версии не показывается. Доступны также Firefox 148, Safari 26.3, Edge 85, iOS 14, Android/OkHttp 11, QQ 11.1, 360 7.5, Random и Randomized. Старые специальные Chrome-алиасы не являются отдельными профилями и не добавлены в меню.

Random выбирает один из Chrome/Firefox/Safari на время процесса; Randomized генерирует ClientHello с ALPN и постоянным seed на время процесса. Ни один не является случайной «версией браузера». Android и 360 несовместимы с REALITY; Edge/iOS/QQ требуют совместимых старых серверов. **Наследовать из ссылки** снимает отдельный override. Эти настройки не являются HTTP User-Agent или гарантией обхода блокировок. Полный контракт описан в `core/FINGERPRINTS.md` исходного репозитория.

Откройте настройки нужного сервера в списке URI подключения. В этом же окне находятся разбиение ClientHello на две TLS-записи и классический обмен ключами для VLESS REALITY. Поле **TLS fingerprint** позволяет отдельно выбрать `chrome_155`, обычный `chrome` (Chrome 133) или другой предлагаемый профиль. Для `chrome_155` требуется ядро 1.14.4-r9 или новее.

По умолчанию выбран **Inherit from connection URI**: сохраняется fingerprint, заданный исходной ссылкой. Явный выбор меняет только TLS-настройку этой записи; URI и имя сервера сохраняются. Настройка привязана к постоянному ID подключения, поэтому переименование сервера или одинаковые URI у нескольких записей не переносят её на соседние записи. Возврат к наследованию снова использует исходную ссылку.

Override доступен для VLESS, VMess, Trojan, AnyTLS и HTTPS-прокси с уже включённым TLS через TCP. Он не включает TLS у plaintext-соединений и не применяется к QUIC, включая XHTTP с единственным ALPN `h3`. Требуется сборка ядра с uTLS. Проверки доступности используют тот же outbound, что и трафик. Отдельная запись URI не меняет серверы внутри подписки.

## Каскадное подключение

Каскад подключается к серверу через другую секцию. Например, провайдер блокирует ваш сервер, а WARP работает. Создайте секцию с туннелем WARP без условий и включите у ссылки **Каскадное подключение** через неё. Без условий секция не забирает ничей трафик и служит только звеном каскада.

Так же работает каскад у [подписок](/connections/subscriptions) и [туннелей](/tunnels/).
