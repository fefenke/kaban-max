# Верификация issues и PR Forkop с учётом несовместимых веток 1.0.5 и 2.0

Проверено 15 ноября 2026 года по [официальному релизу Forkop 2.0.0](https://github.com/ushan0v/forkop/releases/tag/2.0.0), [релизу 1.0.5](https://github.com/ushan0v/forkop/releases/tag/1.0.5), GitHub issues/PR, комментариям автора и состоянию `main` Forkop (`129d303e6cc879e9edc4e13c50b1f37637e69554` от 02.11.2026). KABANMAX — форк архитектуры 2.0 со своим ядром и Zapret2. Его локальная рабочая копия после правок Codex может быть новее публичного репозитория.

**Правило:** версия исходного репорта != текущая версия приложения. Проблема 1.0.5 не переносится в план исправлений 2.0 без воспроизведения в 2.0, даже если названия функций совпадают. Закрытие issue или PR не равно merge, а комментарий «будет в следующем релизе» не подтверждает попадание в опубликованный релиз 2.0.0.

## Архитектура и граница версий

| | Forkop 1.0.5 | Forkop 2.0.0 и KABANMAX |
|---|---|---|
| Дата релиза | 18.07.2026 | 27.10.2026 |
| Core | `sing-box-extended` / прежняя интеграция | Forkop — `sing-box-forkop`; KABANMAX — собственный `sing-box-kabanmax` |
| Zapret2 | Встроен в прежней архитектуре | Официальный Forkop 2.0 удалил Zapret, Zapret2 и ByeDPI; KABANMAX восстановил **свою** интеграцию Zapret2 |
| Рабочий ориентир для исправлений | Только при подтверждении в новой архитектуре | Актуальный код и регрессионные тесты локального KABANMAX |

## Требование каждому Codex

1. Зафиксировать версии **из конкретного репорта** и текущей локальной сборки, а не судить по номеру issue или дате закрытия.
2. Если репорт относится к 1.0.5: сравнить старую и новую архитектуру; если сценарий уже нерелевантен — **не чинить**.
3. Для 2.0: проверить исправление в `main`/ядре и применимость к KABANMAX. Нет тестового воспроизведения — только явный тест/документация, не масштабный рефакторинг.
4. Для PR: отдельно статус **closed / merged**. Закрытые без слияния PR не считать официальными фиксами, даже если автор вручную реализовал похожее в другом коммите.
5. В KABANMAX не заменять новые механизмы 2.0 старыми файлами или патчами 1.0.5.
