# План проверочного комплекта 0.2.3

Исполнение одним текущим ассистентом по прямому запросу пользователя; без субагентов, публикации и изменения соседних проектов.

**Цель:** собрать существующие исправления авторутинга, журналов, DNS/WAN/FakeIPv6 и WARP в согласованный preview 0.2.3 / core r29, проверить и установить на разрешённый локальный роутер для нескольких дней пользовательской приёмки.

**Состав:** текущее рабочее дерево приложения/LuCI/переводов; pinned `core/UPSTREAM` + все 29 patches. Текущий пользовательский diff сохраняется. Новые продуктовые функции не добавляются.

1. Проверить полный frontend + TypeScript/build, целевой lint, backend suite и syntax изменённых ucode, все затронутые core race suites на чистой серии, docs gate.
2. Собрать 0.2.3 app/backend/RU и r29 base/tiny APK/IPK, сверить manifests/SHA256/payload с исходниками. Сборочные инструменты только в локальном контейнере; не отправлять приватный build context.
3. До установки прочитать metadata/free space, сохранить приватный backup конфигурации/autoroute и известный рабочий комплект без вывода секретов. Перед паузой предупредить пользователя; автономный router-side таймер запуска/отката должен пережить потерю связи ассистента. Не складывать ядро и backup в tmpfs.
4. Установить проверенный комплект на один роутер; сохранить профильные credentials и routes/exclusions, не включать автоматику/Debug самовольно. Проверить app/core versions, UCI validation, registry, journal/monitoring bounds, FakeIP config, WARP и реальные HTTPS/видеоданные без нагрузки.
5. Обновить PROJECT_STATE/контракты/отчёт с точными командами, результатами и ограничениями; GitHub push/release не выполнять. Длительную приёмку выполняет пользователь.

**Откат:** известные рабочие файлы/metadata сохраняются перед заменой. Router-side watchdog при неуспешном старте возвращает рабочий комплект и запускает службу; при невозможности автоматического восстановления пользователь предупреждён заранее.

**Границы:** чистые mock/race suites не заменяют ARM64 soak; свежий hardware smoke не доказывает устранение общего OOM. Публикация только по новому запросу после приёмки.

Исполнено 2026-11-23: все пять этапов завершены, suites/package inspections PASS; штатный install.sh установил 0.2.3/r29 и запустил службу (exit 0). Ruling: отдельная deployment-обвязка оказалась ошибочной (`reload` skipped → exit 0); она отменена, для окончательной установки использован штатный installer/local mirror по требованию пользователя. Подробные результаты и ограничения: [PREVIEW_023](../../PREVIEW_023.md). Пользовательская длительная приёмка и GitHub публикация не входят в выполненную установку.
