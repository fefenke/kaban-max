# План изоляции KABANMAX

**Цель:** самостоятельный checkout с сохранённой историей, приватными исследованиями и компактным контекстом для новых сессий.
**Архитектура:** текущий репозиторий в корне; локальные legacy/core/research под игнорируемой `.local`; документация навигирует по актуальному коду.
**Основание:** пользовательское задание «Полная изоляция, аудит, очистка и документирование проекта KABANMAX», 2026-11-13. Пользователь явно разрешил последовательное автономное выполнение безопасных этапов без дополнительного согласования плана.

## Ограничения
Не менять соседние проекты, живую инфраструктуру и working algorithms; не публиковать приватные данные; не терять историю/dirty state.

## Этапы
- [x] Инвентаризация: candidates, hashes, Git HEAD/status/refs/diff; bundles и top-level baseline соседей.
- [x] Перенос текущего checkout, связанной пары legacy/worktree и core/research; repair Git pointers.
- [x] Проверка файлов по manifest и изоляции build context; архив перед удалением только generated сайта.
- [x] Документация по актуальным модулям; история и гипотезы отделены от подтверждённого.
- [x] Fresh frontend/backend/core проверки из отдельных snapshots; build сайта и пакетирование приложения.
- [x] Финальная сверка doc links, приватности, Git/архивов и отчёт.

## Особые проверки
Windows case collision INDEX/index; Linux node_modules reparse; dirty core new files; worktree gitdir; отсутствие ссылок на старые mounts; исключение .local из site/Docker/Git. Результаты и отклонения — `.local/audit/` и TESTING.
