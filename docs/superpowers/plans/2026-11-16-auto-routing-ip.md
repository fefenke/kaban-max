# Исправление автомаршрутизации по IP

**Goal:** Ошибка своей Zapret-секции с фактическим IP приводит к последовательной проверке Zapret → Direct → WARP и явному предложению рабочего назначения.

**Architecture:** Сохраняем структурированный адрес неудачного dial, подтверждаем domain/IP через DNS. Без подтверждения формируем IP-only scope. Существующие ограничения секции, устройств, инфраструктуры и first-match сохраняются. Изменения ядра поставляются новым patch к закреплённому upstream.

**Tech Stack:** Go, ucode, TypeScript/LuCI.

**Spec:** Уточнения пользователя в текущем диалоге: подтверждённая связь domain/IP означает правило для пары, иначе правило для IP; последовательность Zapret, Direct, WARP; принять/исключить/удалить; выбор WARP fallback.

## Global Constraints

- Только локальные изолированные проверки, без роутеров/VPS, публикации и установки.
- Фактический IP нельзя выбирать произвольно из DNS-набора.
- Подтверждение обмена данными обязательно; TCP dial сам по себе не доказывает рабочий путь.
- Не ослаблять ACL, RU/infrastructure guards, first-match и ограничения scope.

## Review Focus

- Ошибка dial при нескольких A/AAAA сохраняет фактический адрес.
- Неподтверждённый домен не становится доменным правилом.
- Direct имеет приоритет над WARP; неработающие альтернативы не получают Apply.
- Fallback допускается только с WARP-участниками и безопасным detour.
- Новый сбой не перезаписывает готовое предложение устаревшим результатом.
