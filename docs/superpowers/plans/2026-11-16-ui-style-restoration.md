# Восстановление оформления форм — Implementation Plan

**Goal:** Перенести утверждённый стиль в общие формы KABANMAX, уменьшить стрелки и исправить невозможность выключения auto-apply.

**Architecture:** Общий CBI-адаптер сохраняет одну колонку полей и компактную синюю справку; список использует существующие RPC. Core и сетевые алгоритмы не меняются.

**Tech Stack:** TypeScript, LuCI CBI, Vitest, headless Edge/CDP.

**Spec:** [Утверждённый макет](../../audits/UI_STYLE_PROPOSAL.md). Дополнение пользователя: компактные стрелки, общий стиль настроек; удаление всех записей текущего фильтра только выбранного списка «Применены»/«Исключены».

## Ограничения

Работа в текущей папке с сохранением существующего документа и макета. Публикация 0.1.8 разрешена последующим сообщением пользователя после готовности; подключения к оборудованию запрещены. Пользователь утвердил стиль; поведение недоступных возможностей сохраняет backend-ограничения. Блокировка повторного включения без strict не должна препятствовать снятию сохранённой галочки.

## Задачи

- [x] Добавить браузерную регрессию снятия auto-apply без контракта и при выключенной главной галочке; увидеть RED, исправить и получить GREEN.
- [x] В `cbi/formUx.ts` восстановить общую колонку, синие help, убрать вложенные отступы; сохранить узкий экран, textarea и lifecycle. Справку списка перенести к заголовку через стандартный CBI description.
- [x] В `sections/autoRecords.ts` уменьшить стрелки и выровнять страницы вправо; убрать временную остановку и постоянную справку, сохранить ошибки и overflow warning. Для «Применены» добавить массовое `forget`, для «Исключены» сохранить `remove`, по всем страницам фильтра с подтверждением и текущим source scope.
- [x] Проверить массовое удаление обеих вкладок, отмену подтверждения, scope/filter и частичные результаты. Выполнить browser matrix, frontend tests, lint/build, diff check. Снять скриншоты реальных компонентов с тестовой LuCI-разметкой; обновить затронутые документы точными результатами.

## Review Focus

Форма настроек и модалки; узкие экраны и темы; уже включённое разрешение при невалидном контракте; отсутствие права включить новый обход; live и saved записи при массовом forget; сохранение предупреждений и результатов RPC. Визуальные снимки CBI-fixture не заменяют приёмку установленной темы.

## Исполнение

Выполняется последовательно в текущей сессии по подтверждённому пользователем варианту. Отдельный worktree не создаётся; Git-история и исходные артефакты сохраняются. Изменения и свежие команды будут записаны в отчёте восстановления оформления.
