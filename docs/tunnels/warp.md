# Cloudflare WARP

Бесплатный VPN Cloudflare без своего сервера. Через него работают YouTube, Discord и сайты, которые блокирует РКН.

Cloudflare выдаёт адрес страны, из которой к нему подключились. Поэтому сервисы, закрытые для России, например ChatGPT и Gemini, через WARP не откроются. Для них нужен [WARP в другой стране](#warp-в-другои-стране).

## Создать туннель

1. Секция → **Добавить туннель** → **Тип туннеля**: **Cloudflare WARP**.
2. Нажмите **Сгенерировать профиль**.
3. Включите **Обфускацию трафика**, нажмите **Сгенерировать параметры**.

Без обфускации провайдеры в России режут WARP. Часто закрыт и `api.cloudflareclient.com`, через который идут регистрация и профиль. Если **Сгенерировать профиль** не срабатывает, включите в настройках **Запрашивать WARP через секцию** и выберите секцию с рабочим подключением. Трафик туннеля всё так же пойдёт напрямую или через каскад из его настроек.

Если у вас есть WARP+, впишите ключ из приложения 1.1.1.1 в поле **Лицензионный ключ**.

## Применение и запуск

Запросы профиля работающего туннеля используют выбранную секцию, в том числе при автоматической регистрации без заполненных реквизитов. Если запрос через секцию выключен, используется прямой outbound ядра с mark обхода собственного перехвата. Этот выбор относится только к Cloudflare API; каскад и маршрут пользовательского трафика задаются отдельно. При недоступности выбранной секции прямой запасной маршрут для API не включается.

Сохранение без изменения генерируемой конфигурации не перезапускает ядро. Настоящее изменение JSON, в том числе другой активной секции, требует reload всего sing-box и закрывает существующие соединения. Смена обфускации туда-обратно не является способом восстановления: она вызывает повторную инициализацию вместе с остальными endpoint.

Первое применение исправленного генератора добавляет API detour в прежний JSON и поэтому потребует одного обычного reload; последующие сохранения без изменений его не повторяют. Для туннеля типа **JSON** маршрут API задаётся внутри пользовательского JSON явно и автоматически не переписывается.

Валидный кэш профиля используется без обращения к API; смена реквизитов/лицензии или имени туннеля меняет его идентичность. По умолчанию кэш `/tmp/sing-box/cache.db` вместе с соседними файлами временный: после перезагрузки нужен доступ к Cloudflare API даже для ранее зарегистрированного профиля. Три поля регистрации не содержат полного WireGuard-профиля с адресами и peer. Ошибки API повторяются с интервалом 5, 10, 20, 40, затем 60 секунд до успеха или остановки endpoint; пока он не готов, обращения к нему завершаются ошибкой. Проверьте WAN, DNS и системное время; локальные тесты не доказывают доступность Cloudflare у провайдера.

## WARP в другой стране

Включите у туннеля **Каскадное подключение** через секцию с сервером в нужной стране. Cloudflare выдаст WARP адрес этой страны, например каскад через сервер во Франции даёт WARP Франции.
