# Установка

**K.A.B.A.N.-MAX 0.1.3 · предварительная версия**

| Система | Формат пакетов | Архитектура |
|---|---|---|
| OpenWrt с apk | APK | `aarch64_cortex-a53` |
| OpenWrt с opkg | IPK | `aarch64_cortex-a53` |

## Через SSH

```sh
wget -O /tmp/kabanmax-install.sh https://raw.githubusercontent.com/fefenke/kaban-max/main/install.sh && KABANMAX_RELEASE=0.1.3 sh /tmp/kabanmax-install.sh --variant base --lang ru
```

Установщик определяет пакетный менеджер и архитектуру, скачивает компоненты, проверяет SHA256 и устанавливает приложение с русским переводом.

После установки откройте **Службы → K.A.B.A.N.-MAX**. Добавьте подключения и настройте секции по [инструкции быстрого старта](./quick-start). Для использования Zapret2 установите его на вкладке **Компоненты**.

## Варианты ядра

- **base** — VPN-протоколы, WARP, WireGuard и OpenVPN. Выбран в команде выше.
- **tiny** — компактный набор протоколов. Для установки замените `--variant base` на `--variant tiny`.

## Скачать пакеты

В [выпуске 0.1.3](https://github.com/fefenke/kaban-max/releases/tag/0.1.3) находятся пакеты приложения, интерфейса, перевода и ядра. Выберите APK или IPK по пакетному менеджеру роутера. Контрольные суммы находятся в `SHA256SUMS`.

Для установки с автоматическим подбором зависимостей используйте команду выше.

## Обновление

Откройте **Компоненты → KabanMax → Проверить обновления**. Если доступно обновление, кнопка сменится на **Скачать и установить обновление**. Во время установки отображается состояние операции; подробный журнал можно раскрыть ниже.

Для обновления через SSH запустите установщик повторно с номером нужного выпуска в `KABANMAX_RELEASE`.

## Удаление

```sh
sh /tmp/kabanmax-install.sh --uninstall
```

Удаление вместе с настройками приложения:

```sh
sh /tmp/kabanmax-install.sh --uninstall --purge
```
