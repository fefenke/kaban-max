# Установка и переход

Предварительная версия **2.1.0**, архитектура **aarch64_cortex-a53**. Пакеты IPK для OpenWrt с opkg, APK для OpenWrt с apk. Другие архитектуры пока требуют отдельной сборки и проверки.

## Через SSH

Проверьте `cat /etc/openwrt_release`, свободное место `df -h /overlay` и память `free`. Создайте собственную резервную копию настроек до миграции.

```sh
wget -O /tmp/kabanmax-install.sh https://raw.githubusercontent.com/fefenke/kaban-max/main/install.sh && KABANMAX_RELEASE=2.1.0 sh /tmp/kabanmax-install.sh --variant base --lang ru
```

`base` включает VLESS/Reality, WARP и WireGuard. `tiny` меньше по набору протоколов. Full с интегрированным Tailscale/NaiveProxy пока не поставляется. Если используется системный Tailscale, оставьте его отдельным пакетом.

Установщик скачивает согласованные версии backend, LuCI, перевода и ядра из одного выпуска, сверяет SHA256, затем применяет установку. Неподдерживаемый пакет или архитектура должны быть выявлены до замены установленных компонентов. Не используйте `--force-depends`.

## Уже установлен Forkop

Имена пакетов и UCI остаются `forkop`, служба — `/etc/init.d/forkop`. Настройки мигрируются существующим механизмом. Не переносите целиком настройки другого роутера. PPPoE, Wi-Fi, LAN и Tailscale сохраняют собственную конфигурацию.

С 1.0.5 могут отличаться доступные типы туннелей и стратегии. Особенно проверьте полный набор протоколов до замены full-ядра. Сторонний самостоятельный Zapret2 нельзя одновременно запускать с интеграцией на пересекающихся очередях: приложение проверяет конфликты. Не удаляйте его файлы наугад.

Новый fallback требует **sing-box-forkop 1.14.4-r2** из этого же выпуска. Старое ядро не понимает новые поля. Не устанавливайте один интерфейс отдельно от backend и ядра.

## Ручная установка

В [выпусках](https://github.com/fefenke/kaban-max/releases) скачайте `forkop`, `luci-app-forkop`, `luci-i18n-forkop-ru` версии 2.1.0 и `sing-box-forkop` 1.14.4-r2 нужного варианта. Расширение выбирается по пакетному менеджеру. Сверьте `SHA256SUMS`, передайте в `/tmp` и установите зависимости через пакетный менеджер OpenWrt. Рекомендуется установщик: он выполняет проверки и откат при ошибке.

После установки откройте **Службы → K.A.B.A.N.-MAX**, обновите страницу без кэша браузера. Установите Zapret2 в «Компонентах», если он нужен. Проверяйте журнал `logread -e forkop` и диагностику LuCI.

## Обновление и удаление

Для повторной установки этого preview используйте ту же команду. Стабильный канал `/latest` предварительную версию не выбирает; новый preview устанавливается с явным номером `KABANMAX_RELEASE`.

```sh
sh /tmp/kabanmax-install.sh --uninstall
```

Для удаления вместе с настройками добавьте `--purge`. Это необратимо для настроек приложения; собственные системные настройки сети не удаляются. Не скачивайте установщик из случайных зеркал.
