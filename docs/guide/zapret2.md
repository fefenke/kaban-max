# Zapret2

Компонент устанавливается и обновляется из официальных выпусков bol-van/zapret2 через вкладку «Компоненты». Это отдельное обновление от backend и ядра VPN.

Создайте секцию Zapret2 и назначьте ей только нужные домены/списки. Стратегии проверяются перед применением. Разные секции используют собственные очереди; K.A.B.A.N.-MAX управляет своими nftables и процессами nfqws2. Не запускайте параллельно сторонний firewall-скрипт Zapret2 с теми же очередями.

Нужны модули `kmod-nfnetlink-queue` и `kmod-nft-queue`, совпадающие с ядром установленной OpenWrt. Если они недоступны в репозитории, не форсируйте установку несовместимых kmod.

Проверки в SSH:

```sh
forkop zapret2_status
cat /proc/net/netfilter/nfnetlink_queue
logread -e forkop-zapret2
```

Пустой список очередей при активных секциях — повод изучить журнал. `did not bind its NFQUEUE queues` означает отсутствие ожидаемых привязок, а не автоматически ошибку стратегии. Проверьте модули, права файлов Lua/fake и конфликты служб.
