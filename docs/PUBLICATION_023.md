# Публикация 0.2.3 / r46

Дата проверки: **2026-11-27**. Scope: исходники проекта, все 35 прежних коммитов и 14 тегов, 14 GitHub releases, 198 исходных assets; ARM64 base/tiny APK/IPK r46 и соответствующие исходники. Роутеры в этой задаче не подключались и не обновлялись.

## Оформление

Изучены README [Yandex-Disk-Rescue](https://github.com/fefenke/Yandex-Disk-Rescue), [OpenClash](https://github.com/vernesong/OpenClash), [Passwall](https://github.com/Openwrt-Passwall/openwrt-passwall) и [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev). Применены видимая установка, компактная навигация, таблицы возможностей, схема маршрутов и подробности после быстрого старта. README описывает продукт; заключительная атрибуция сохранена. Руководство установки, страница сайта и описание исходников ядра согласованы с 0.2.3/r46.

## Приватность и история

Пользователь отдельно разрешил перепись истории и старых тегов. Перед изменением сохранены Git bundle, карта исходных refs и все release assets; 181 уникальный файл проверен по размеру и GitHub SHA256. Копии находятся в игнорируемом локальном каталоге и не публикуются.

Проверены ключи, токены, почтовые адреса, локальные пути, инструментальные метки и четыре точных значения из приватной конфигурации. Найденные старые служебные метаданные PNG удалены без изменения IDAT; старые заголовки переводов обезличены, метки в документах и тестовых данных заменены. Очищенный граф из 35 коммитов сохраняет родителей и функциональные версии. Проверка 29 090 файловых записей: **0 находок**.

В 13 прежних выпусках заменяются только два LuCI-пакета и SHA256SUMS. Сравнение исходных и подготовленных пакетов: единственное отличие payload — метаданные PNG; сжатые пиксели, программный код и APK-сценарии идентичны. APK/IPK payload и суммы каждого выпуска согласованы. Старые версии ядра не подменяются r46.

Публичные обязательные уведомления upstream/GPL, контакт внутри публичного CA-сертификата и идентификатор расширения OpenSSH сохранены. Они проверены отдельно и разрешены точными отпечатками; это не исключение для пользовательских секретов. В архиве исходников r46 убран только служебный комментарий списка упаковки, без изменения исполняемого кода. Исходники прежнего r41 также сохраняются рядом с соответствующими суммами.

Перепись публичных refs не удаляет сторонние клоны, форки и кэши. Проверка известных шаблонов и точных значений не является доказательством отсутствия всех возможных секретов.
